# Figure and table source archive

[Asset catalogue](Candidate_Asset_Register_v0.7.csv) lists source files and statistical definitions. [Captions](Candidate_Captions_and_Response_Uses_v0.4.md) explain the quantities displayed. `01_Main_Candidates/`, `02_Supplement_Candidates/` and `03_Response_Reserve/` retain their source-relative directory names. The third folder contains additional analyses. Historical figure/table versions and rendered draft labels are archive provenance; not every archived asset belongs in the manuscript. Current Figure 2 has panels a/b; CF04 is an earlier standalone source for panel b.

`04_Data_and_Provenance/` contains the original rendering manifests. These document the original files, not checksums for normalized public documentation. Use the current package manifest for byte verification.
