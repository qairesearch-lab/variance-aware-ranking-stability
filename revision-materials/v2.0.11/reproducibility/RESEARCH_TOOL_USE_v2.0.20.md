# Research tool use and code provenance

The original experimental codebase was supplied by the authors. The extension reused the existing training workflow with dataset-specific adaptations. During revision, Codex (OpenAI) assisted with revision-specific post-training analysis and visualization scripts, literature-source checks, reproducibility packaging and manuscript-revision materials. Scientific decisions and responsibility for the analyses and manuscript remain with the authors. Computational cross-checks used different implementations within this assisted workflow and are not described as independent personnel review.

The original experimental codebase and torchvision model implementations are not attributed to Codex or OpenAI. The disclosure concerns the revision-stage assistance described above.
