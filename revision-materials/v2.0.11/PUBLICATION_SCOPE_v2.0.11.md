# Publication scope (current export v2.0.19)

Author-generated processing code, evaluation records and derived benchmark identifiers are shared for reproducibility. Original dataset images, archives, pretrained weights, checkpoint binaries and individual prediction arrays are acquired or retained separately. The existing repository MIT notice is retained for authored code; third-party benchmark access/use terms are unchanged.

Numerical inputs, results and frozen training records preserve their original bytes. Public documentation and portable wrappers are identified in the current export mapping. Original execution hashes remain historical provenance; the v2.0.19 package manifest verifies current files. Internal editing records and superseded prose drafts are excluded from current files.

The original submission release and previous revision-material commit/tag remain historical snapshots. File identity checks are not independent model replication or independent personnel review.
