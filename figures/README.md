# Selected figures

Figures 1–3 and supplementary Figures S1–S2 correspond to the current manuscript. Each selected figure is provided in PNG, SVG and PDF. Numerical source data are in `data/` and the supplementary tables. Rendering scripts recreate main plots from saved values; styling and output metadata may vary across environments.

**Fig. 1 Observed model selection frequencies across repeated evaluations.** Observed selection frequencies f are calculated across 50 original or 30 extension split–seed contexts per stratum. R18, R50, D121, and E-B0 denote ResNet-18, ResNet-50, DenseNet-121, and EfficientNet-B0. Error bars show model-specific 95% paired crossed split–seed percentile intervals based on 10,000 resamples. Table 1 agreement intervals reselect the reference model in each resample. Intervals for unobserved selections may be degenerate. Paired bootstrap selection frequency q is reported separately in Table 1

**Fig. 2 Performance separation and sensitivity of model selection to evaluation conditions.** (a) Differences between the two highest BA values within each observed split–seed context, in percentage points (pp). The leading pair is reselected within each context. Boxes show the median and interquartile range; whiskers extend to the most extreme observations within 1.5 interquartile ranges of the box, and points show all contexts. Subplot y-ranges differ. (b) Fractions of paired contexts selecting different models under A/B evaluation procedures (left) or after adding Swin-T to four convolutional neural networks (CNNs) with shared dataset preprocessing (right). Horizontal bars show 95% pointwise percentile intervals from 10,000 paired crossed split–seed resamples. A/B uses ten splits and five seeds per original dataset and jointly differs in checkpoint selection and training termination. Candidate pools are compared on the same five splits and three seeds per extension dataset. Complete contrasts are reported in Supplementary Tables S5 and S8

**Fig. 3 Model selection agreement across budgets for repeated evaluation.** Each point averages agreement after aggregating candidate balanced accuracy (BA) over all eligible discovery subsets within 252 oriented partitions of the ten split identifiers into two groups of five. The reference uses mean BA on the five held-out split identifiers and all available seeds. Lines indicate the number of training seeds: one to five for the original experiments and one to three for the extension experiments. Shading for the three-seed line shows the 2.5th–97.5th percentile spread across the finite set of partitions, rather than a population confidence interval. Four-candidate training-run budgets equal four times the number of discovery splits times the number of seeds. The two groups contain different split identifiers; source images may recur across split realizations

**Fig. S1 Original experimental evaluation matrix.** The registered matrix crossed two datasets, four CNN candidates, ten repeated holdout splits, five training seeds and two evaluation procedures, yielding 800 original runs. The 300-run reviewer-requested extension is itemized separately in Table S1, Panel C

**Fig. S2 Original observed computational cost and agreement with the full repeated evaluation reference.** Each panel shows an original dataset / procedure stratum. Circles denote reduced budgets; x-values are mean observed elapsed GPU hours for four candidates across enumerated subsets. The x-axis is logarithmic and the y-axis is truncated. Hollow squares denote the deterministic 10×5 self-comparison. Error bars retain the original Wilson interval calculation applied to historical subset-agreement counts. These historical intervals do not quantify sampling variability across independent samples and are distinct from the finite-partition percentile bands in revised main Fig. 3. The original figure and source values are retained without recomputing costs or comparing hardware
