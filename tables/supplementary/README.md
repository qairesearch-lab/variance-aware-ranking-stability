`Observed_Budget_Reference_Identities.csv` reports all 252 oriented five-split/five-split partitions for SIPaKMeD procedure B. It gives the discovery/reference split IDs, the observed mean-BA reference model, the saved bootstrap-frequency mode, and the mean BA by model. It is a deterministic view of existing run inputs and saved reference frequencies. `source_run_input_sha256` identifies the distributed `analysis/results/B1_run_inputs.csv`; no new training or bootstrap draws were performed to create this table.
